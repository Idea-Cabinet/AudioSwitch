# AudioSwitch

> 极轻量、免依赖的 Windows 双音频输出设备快速切换利器。  
> 原生 C++ 实现，支持单键/修饰键/双键组合（Chord）、动态设备自愈、可视化按键录制与托盘图形配置。

---

## ✨ 核心特性

- ⚡ **极致轻量纯粹**：原生 Win32 / C++ 开发，零运行库依赖（无 .NET、无 Electron、无 Python），闲置内存仅约 **1 MB**，零 CPU 占用；无键盘轮询、无驱动、无任何 Shell 进程注入。
- 🔄 **任意双设备一键切换**：自由绑定任意两个系统播放端点（如：**音箱 ⇋ 耳机**、**显示器音频 ⇋ 耳麦**、**USB DAC ⇋ 蓝牙耳机**等），一键即刻在两个设备间平滑切换。
- 🛡️ **动态设备识别与自愈**：彻底解决 Windows 在电脑重启、休眠唤醒、显示器休眠或插拔后重新分配音频端点 GUID 导致配置失效的业界顽疾。程序通过友好名称与硬件描述动态精确定位当前活跃端点。
- 🎨 **可视化图形配置界面（GUI）**：系统托盘右键一键打开“快捷键与设备设置”窗口：
  - 音频设备直观下拉选择，显示驱动描述与硬件接口类型，支持“试切此设备”即时试听；
  - 热键支持**点击【🎯 录制】后直接敲击键盘一键捕获**，亦可从 F13~F24 等常用功能键下拉预设；
  - 支持配置切换通知气泡（亦可开启静默切换免打扰模式）；
  - 保存后即刻热重载生效，无需重启程序。
- ⌨️ **强大的按键支持与外设联动**：
  - **单键 / 修饰键模式**：支持任意单键（如 F13、F14）或组合键（Ctrl / Alt / Shift）；
  - **双键组合模式（Chord）**：支持如 `End + PgUp` 等双键协同触发，底层基于轻量键盘 Hook 拦截触发键翻页消息，不漏键、不连发；
  - **客制化/可编程键盘绝配**：非常适合搭配支持 VIA / QMK 的客制化键盘、洛斐小顺系列、NuPhy、Keychron 等可编程键盘，将某一按键映射为 `F13`，实现真正的“桌面物理一键盲切”。
- 🔕 **贴心的桌面交互**：
  - 双击系统托盘图标即切换音频；
  - 支持“隐藏托盘图标”完全无感后台静默运行（再次双击程序 EXE 即可重新唤出托盘）；
  - 支持一键开机自启（仅写入当前用户注册表 Run 项，绿色干净，不注册 Windows 服务或任务计划）；
  - 支持同目录 `AudioSwitch.ico` 自定义托盘图标。

## 🎯 典型使用场景

1. **日常桌面音响与耳机无缝切换**  
   白天外放听歌、看视频，开会或深夜游戏时一键切到有线/无线耳机，彻底告别繁琐翻找 Windows 声音控制面板。
2. **搭配客制化 / 可编程键盘一键盲切**  
   在键盘改键工具（如 VIA、驱动配置软件）中将某个闲置键或旋钮映射为 **F13**（键码 124），敲击该键即刻完成声道转移，无需录制繁杂宏。
3. **游戏 / 观影免打扰静默切换**  
   在设置面板中取消勾选“切换音频时弹出系统通知气泡”，热键切换时只改声道、不弹气泡、不抢窗口焦点。

## 🚀 快速上手

### 1. 下载与运行
从 [GitHub Releases](https://github.com/Idea-Cabinet/AudioSwitch/releases) 下载最新发行版压缩包，解压至任意目录，双击 `AudioSwitch.exe` 启动。

### 2. 配置音频设备与快捷键
右键点击右下角系统托盘中的喇叭图标，选择 **“快捷键与设备设置(&S)...”**（或命令行执行 `AudioSwitch.exe --settings`）：
1. **音频设备**：在“设备 1”和“设备 2”下拉列表中分别选择要来回切换的两个音频输出；点击右侧“试切此设备”可立即试听。
2. **切换热键**：
   - **单键/修饰键**：可勾选 Ctrl/Alt/Shift，点击【🎯 录制主键】直接在键盘上按下目标键（默认推荐 F13），或从下拉列表选择。
   - **双键组合（Chord）**：如选择 End+PgUp，按住前导键再按触发键即可切换。
3. **通知设置**：按需勾选或取消“切换音频时弹出系统通知气泡”。
4. 点击 **“保存并生效”**，热键即时更新生效。

## ⚙️ 配置文件说明（可选）

程序默认将配置持久化在程序同目录的 `audio-switch.ini` 中，亦可直接手动编辑（参考 `audio-switch.example.ini`）：

```ini
[Devices]
; 每次切换时动态根据 FriendlyName 与 Desc 智能匹配当前最新活跃设备 GUID
Device1Friendly=DELL S2725QS (NVIDIA High Definition Audio)
Device1Desc=DELL S2725QS
Device1Interface=NVIDIA High Definition Audio

Device2Friendly=耳机 (High Definition Audio Device)
Device2Desc=耳机
Device2Interface=High Definition Audio Device

[Hotkey]
; VirtualKey: 键码（124 = F13，33 = PgUp）
; Modifiers: 0=无，1=Alt，2=Ctrl，4=Shift（相加组合）
; ChordKey: 双键组合的前导键（0=单键模式，35=End）
VirtualKey=124
Modifiers=0
ChordKey=0

[UI]
; 是否显示系统托盘图标（1=显示，0=隐藏）
ShowTray=1
; 切换音频时是否弹出系统通知气泡（1=显示，0=静默免打扰）
ShowNotification=1
```

## 💻 命令行用法

`AudioSwitch.exe` 支持丰富的命令行参数，可方便与外部脚本、快捷方式或批处理协同：

| 参数 | 说明 |
|---|---|
| *(无参数)* | 启动后台监听；若已有实例运行，则恢复显示其托盘图标 |
| `--background` | 静默启动监听，遵循用户保存的托盘隐藏偏好 |
| `--toggle` | 执行一次音频切换并立即退出（适合通过第三方快捷指令调用） |
| `--settings` / `--config` | 唤出图形化配置设置窗口 |
| `--show-tray` | 恢复显示托盘图标 |
| `--hide-tray` | 隐藏托盘图标（快捷键继续保持监听） |
| `--autostart-on` | 开启当前用户登录自启动 |
| `--autostart-off` | 关闭开机自启动 |
| `--exit` | 安全退出当前正在运行的后台实例 |
| `--self-test` | 运行双向切换自测（测试后自动恢复原状态） |

## 🛠️ 源码构建

本项目采用精简无第三方库的 C++ 编写，仅需标准 Windows C++ 编译环境即可构建：

1. 安装 Visual Studio 或 Build Tools（包含“使用 C++ 的桌面开发”工作负载与 Windows SDK）。
2. 在项目根目录执行：
   ```bat
   build.cmd
   ```
3. 脚本将自动通过 `vswhere` 定位 MSVC 工具链，生成静态链接的独立二进制文件 `build\AudioSwitch.exe`。

## 📝 技术细节与说明

- **音频切换机制**：基于 Windows Core Audio API（`IMMDeviceEnumerator`）遍历设备信息；通过 `IPolicyConfig` 接口无缝修改系统的 `eConsole` 与 `eMultimedia` 默认播放端点（不影响麦克风输入与 Communications 通讯角色）。
- **进程自启机制**：注册表项写在当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，无需管理员权限，绿色无残留。
- **自定义图标**：在 EXE 同级目录下放置 `AudioSwitch.ico` 文件（建议包含 16×16、32×32 尺寸），重启程序即可显示自定义托盘图标。
- **第三方应用适配**：部分音乐播放器或专业音频软件若在自身设置中硬编码固定了输出声卡，请在软件内将播放设备设为“系统默认设备”。
